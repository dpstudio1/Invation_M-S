# ‎دعوة زفاف إلكترونية فاخرة — Luxury Wedding Invitation

تجربة سينمائية تفاعلية لدعوة زفاف فاخرة: مقدمة سينمائية، أبواب ملكية تنفتح، مشهد قاعة أفراح، أسماء العروسين، صورهما، عدّاد تنازلي، القاعة والموقع على الخريطة، موسيقى خلفية، وخاتمة راقية.

---

## اختصارات سريعة

| مهمة | أين |
|---|---|
| الأسماء والتواريخ والقاعة والموقع والموسيقى والصور | `js/config.js` |
| الصور الشخصية | `assets/images/` (عدّل مساراتها في `config.js`) |
| ملف الموسيقى | `assets/audio/wedding-music.mp3` |
| مشهد القاعة | `assets/images/hall.svg` (عدّل مساره في `config.js`) |
| الخطوط | `assets/fonts/` |

---

## تشغيل المشروع

افتح `index.html` مباشرة في المتصفح، أو الأفضل عبر خادم محلي:

```bash
cd wedding-invitation
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

> للانتقال السريع إلى داخل الدعوة (تجربة ما بعد الافتتاح) أضف `?open` إلى الرابط: `http://localhost:8080/?open`

---

## التخصيص (كل شيء من ملف واحد)

افتح `js/config.js` وعدّل:

1. **المُعرسان** — الاسم بالعربية والإنجليزية + الحرفان الأوّلان لشعار `monogram`:
   ```js
   groom: { ar: "العريس محمد", en: "THE GROOM", firstName: "M", lastName: "A" },
   bride: { ar: "العروس سارة",  en: "THE BRIDE", firstName: "S", lastName: "A" },
   ```
2. **موعد الزفاف** — العرض النصّي و`countdownDateTime` (صيغة ISO: `سنة-شهر-يومTساعة:دقيقة`):
   ```js
   wedding: {
     dateLabelAr: "الجمعة — ٢٥ ديسمبر ٢٠٢٦",
     dateLabelEn: "FRIDAY · DECEMBER 25, 2026",
     ceremonyTime: "الساعة 7:00 مساءً",
     countdownDateTime: "2026-12-25T19:00:00",
   }
   ```
3. **القاعة والموقع** — الاسم والعنوان ورابط خرائط جوجل الحقيقي:
   ```js
   venue: { nameAr: "قاعة الليالي الملكية", addressAr: "…", mapsUrl: "https://maps.google.com/?q=…" }
   ```
4. **الصور**:
   انسخ صورك إلى `assets/images/` بنفس الأسماء الموجودة (ستستبدل الصور التجريبية)،
   أو غيّر المسارات داخل `config.js`.
5. **الموسيقى**: استبدل `assets/audio/wedding-music.mp3` بملفك، أو غيّر `audio.src`.

> 📌 الصور الحالية **صور تجريبية واضحة الاستبدال** (بداخلها نص «ضع الصورة الحقيقية هنا»)؛
> المشروع لا يسقط إذا غيّرت المسارات، بل يعود تلقائيًا إلى الصورة التجريبية مع تنبيه في الـ Console.

## ماذا تحتوي المكاتب الداخلية؟

- **`css/style.css`** — نظام التصميم الفاخر: لون ملكي ذهبي `#d8b45a`، أسود فحمي `#0a0a0d`،
  برغندي عميق `#4a1021`، عاجي `#f2e9d8`، خطوط **Cinzel** (لاتيني فاخر) + **Amiri** (عربي)
  محفوظة محليًا `assets/fonts/`، زخارف هندسية، إطارات ذهبية، فينييت سينمائي،
  جسيمات ضوئية، ومؤثرات تمرير مع دعم `prefers-reduced-motion`.
- **`js/script.js`** — مقدمة سينمائية متدرّجة، فتح الأبواب (منظور ثلاثي الأبعاد)،
  دفع الكاميرا داخل القاعة، جسيمات ذهبية (Canvas)، عدّاد تنازلي يحدّث كل ثانية
  ويعالج التواريخ الخاطئة/المنتهية، الموسيقى (زر تشغيل دون تشغيل تلقائي يخالف المتصفح)،
  ظهور الأقسام عبر `IntersectionObserver`، Parallax خفيف، شريط تقدم، مؤشر تمرير مخصص، ومعرض صور (Lightbox).
- **`assets/images/hall.svg`** — مشهد قاعة أفراح ملكية مرسوم بمنظور حقيقي (قوس مضيء،
  ثريّا ذهبية، أعمدة، ممر، سجادة برغندية).

## ملاحظات تقنية

- **الأداء**: صور `loading="lazy"`، عداد جسيمات يتكيّف مع الشاشة، `devicePixelRatio` بحد أقصى 2،
  وتُوقَف رسوم القاعة/المقدمة بعد الدخول.
- **المتصفحات**: تعمل على الهواتف والأجهزة اللوحية وأجهزة الكمبيوتر؛ الحركات تتقلّص تلقائيًا إذا كان الجهاز ضعيفًا أو إذا فعّل المستخدم `Reduce Motion`.
- **الموسيقى**: لا تُشغَّل تلقائيًا قبل تفاعل المستخدم (سياسة المتصفحات)؛ عند «افتح الدعوة» تُحاول التشغيل، وإذا فشلت يبقى كل شيء يعمل والزر يتحكم بها يدويًا.
- **تم الاختبار**: نحن نتحقق من تعبئة المحتوى من `config.js`، وفتح الدعوة وتسلسله، وأزرار الموسيقى،
  والعدّ التنازلي (تاريخ طبيعي/منتهي/خاطئ)، والوضع المخفّض للحركة، وصحة كل المسارات.
  المعاينة البصرية النهائية في متصفح حقيقي موصى بها قبل المشاركة.
